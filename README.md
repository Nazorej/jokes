# Анекдоты

Программа показывает случайные анекдоты на Python + PyQt6.

## Возможности
- Смена анекдота каждые 30 минут (интервал настраивается)
- Анекдоты не повторяются, пока не покажутся все
- Ручная смена анекдота кнопкой 🎲
- Лайк кнопкой 👍 (❤️ — лайк поставлен, повторное нажатие снимает его)
- История показов и лайков сохраняется в базу SQLite
- Прокрутка длинных анекдотов
- Тёмная тема

## Зависимости

Нужен Python 3 и PyQt6 (модуль sqlite3 входит в состав Python):

```
py -m pip install PyQt6
```

## Подготовка базы данных

Рядом со скриптом должна лежать база `anecdotes.db` с таблицей `anecdotes`:

```
CREATE TABLE anecdotes (text TEXT);
```

Пример заполнения:

```
INSERT INTO anecdotes (text) VALUES
    ('Первый анекдот'),
    ('Второй анекдот');
```

База `history.db` с таблицей истории `history (text, date_time, liked)`
создаётся автоматически при первом запуске.

## Запуск

```
py main.pyw
```

## Настройка

Константы в начале файла:
- `INTERVAL` — интервал смены анекдотов в секундах (1800 = 30 минут)
- `BUTTON_SIZE`, `BUTTON_FONT_SIZE` — размер кнопок и значков на них
- `ANECDOTES_DB`, `HISTORY_DB`, `ICON_PATH` — пути к базам и иконке
